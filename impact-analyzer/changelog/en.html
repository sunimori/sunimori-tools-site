Java Impact Analyzer

Release notes

Main changes in each release, newest first.

  1. 1.4.0.202611211644

    2026-11-22

    • Backend calls of a changed script are grouped by how closely they relate to the change; unrelated ones are folded
    • Right-clicking a page or script with local changes compares it with the last committed version
    • Non-Java folders can be analyzed from the right-click menu
    • Changed functions of a script are listed, and each backend call shows its function
    • A single function can be analyzed from the script editor

  2. 1.3.0.202611202344

    2026-11-21

    • Analyzing a script or page always produces a report
    • The trace from changed files uses the same tree layout as the call tree
    • Affected pages are listed as review items
    • Backend calls made by a changed file are listed as review items
    • Preset notes in the preferences are edited in a table

  3. 1.2.0.202611201323

    2026-11-20

    • Review mode: a preset notes menu, editable in the preferences
    • JavaScript files can be used as a starting point
    • The third review verdict is now "Recheck"
    • Review records can be saved into the report file
    • Review records no longer overwrite each other when one report is open in several windows

  4. 1.1.1.202611200500

    2026-11-20

    • Fixed tag display in return value usage code
    • Return value usage is reviewed together with its caller
    • Release notes show the full version number; the language is chosen from a menu

  5. 1.1.0.202611200254

    2026-11-20

    • "Check for updates" on the preference page; goes online only when clicked
    • Version numbers now go up with each new feature
    • Release notes page on the website

  6. 1.0.0.202611191809

    2026-11-20

    • Call tree grouped by class; same callers merged; parameters folded by default
    • Change set and changed-method panel grouped by class
    • Return value usage code shown once per method
    • Shorter page text
    • Fixed: a long change set no longer widens the page

  7. 1.0.0.202611191405

    2026-11-19

    • New "Return value usage": the report traces who receives a changed method's return value, where it goes and how it is used

Earlier versions are not recorded.
