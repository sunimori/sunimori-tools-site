更新履历

按版本列出主要变化，新的在上。

  1. 1.3.0.202611202344

    2026-11-21

    • 脚本或页面的分析总会生成报告（即使上面没有 Java）
    • 变更文件的追溯以与调用树相同的树显示（行、徽章、代码跳转、验收条都一致）
    • 受影响的页面作为验收项，只计加载或包含该文件的页面（只是跳转过来的位置另列为入口）
    • 列出变更文件调用的后端接口，接收的 Java 作为验收项
    • 设置中的常用备注改为表格编辑（每行一条，一眼看全）

  2. 1.2.0.202611201323

    2026-11-20

    • 验收模式的备注框前增加常用备注下拉框，可在设置中修改，并随页面语言切换
    • JS 文件可以作为分析起点：右键或在变更集中勾选，向上追溯到加载它的页面
    • 验收的第三个结论改为「需再确认」（结论或依据不足时退回）
    • 验收记录可保存到文件：显示未存数量和保存按钮，Chrome / Edge 选一次文件后自动写入
    • 同一报告的记录在两处时不再互相覆盖（合并其他窗口的修改，文件与浏览器不一致时让你选择）

  3. 1.1.1.202611200500

    2026-11-20

    • 返回值流向代码：标签文字上下居中，长行时标签不再被截断
    • 返回值流向不再单独验收，随调用方法一并确认
    • 更新履历显示完整版本号，语言改为下拉选择

  4. 1.1.0.202611200254

    2026-11-20

    • 设置页新增「检查更新」（只在点击时联网）
    • 版本号改为按功能升级
    • 网站新增更新履历页

  5. 1.0.0.202611191809

    2026-11-20

    • 调用树按类分组，同一调用者合并，参数默认折叠
    • 变更集和「变更方法」面板按类分组
    • 返回值流向的代码按方法合并显示
    • 页面文字精简（中、日、英）
    • 修复变更集很长时页面被撑宽

  6. 1.0.0.202611191405
