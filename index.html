インストール（初回のみ） 安装（仅首次） Install (first time only)

先に dropins の jar を消してください。 手で置いた com.sunimori.tools.impactanalyzer_*.jar が eclipse/dropins/ に残っていると二重になり、 どちらが動いているのか判らなくなります。 先删掉 dropins 里的 jar。 手工放进 eclipse/dropins/ 的 com.sunimori.tools.impactanalyzer_*.jar 如果还在， 就会有两份，你无法确定哪份在跑。 Delete the dropins jar first. A hand-placed com.sunimori.tools.impactanalyzer_*.jar left in eclipse/dropins/ gives you two copies and no way to tell which one is running.
  1. Eclipse を起動し、Help → Install New Software…
  2. 启动 Eclipse，Help → Install New Software…
  3. Start Eclipse, then Help → Install New Software…
  4. Add… を押し、Name に Sunimori Tools、 Location に上の URL を貼って Add
  5. 点 Add…，Name 填 Sunimori Tools， Location 粘贴上面的 URL，然后 Add
  6. Press Add…, set Name to Sunimori Tools, paste the URL above into Location, then Add
  7. 一覧に出た Java Impact Analyzer にチェックを入れて Next → ライセンスに同意 → Finish
  8. 勾选列表里的 Java Impact Analyzer， Next → 同意许可 → Finish
  9. Tick Java Impact Analyzer in the list, Next → accept the licence → Finish
  10. 再起動を促されたら再起動
  11. 提示重启时重启
  12. Restart when prompted

未署名の物を拒む設定（任意、推奨） 拒绝未签名内容（可选，推荐） Refuse unsigned content (optional, recommended)

Eclipse の eclipse.ini に次の 1 行を足すと、 署名の無い物は警告ではなく失敗になります。押し通せなくなるので、 すり替えに気付かず入れてしまう事がなくなります。 在 Eclipse 的 eclipse.ini 里加这一行， 未签名的内容会直接安装失败而不是弹警告 —— 没有「仍然继续」可点， 也就不会在没察觉的情况下装上被替换的内容。 Add this line to eclipse.ini and unsigned content fails instead of warning. There is no way to click past it, so a swapped artifact cannot be installed unnoticed.

-Declipse.p2.unsignedPolicy=fail
