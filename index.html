How we build

目立つ機能より、
信頼できる振る舞い。

道具は、使う人の判断を置き換えるものではなく、判断できる材料を静かに整えるものだと考えています。

01

Local first

機密性の高いコードを、分析のためだけに外へ送らない。主要機能はネットワークなしで成立させます。

02

Inspectable

結果だけでなく、どう到達したかを追えること。曖昧さや上限も隠さず、確認可能な形で示します。

03

Focused

巨大な万能製品を目指さず、一つの厄介な仕事を最後まで扱える、輪郭のはっきりした道具を作ります。

01

古い配置を確認

eclipse/dropins/ に手動配置した同プラグインの jar があれば、先に削除します。

02

更新サイトを追加

Eclipse の Help → Install New Software… から、上の URL を追加します。

03

選択して導入

Java Impact Analyzer を選び、ライセンスと証明書を確認して完了します。

04

再起動

案内に従って Eclipse を再起動します。以降は Check for Updates で更新できます。

RELEASE IDENTITY

最初の一度だけ、署名者を確認。

インストール中に証明書の信頼を求められます。署名者と指紋が一致することを確認してから信頼してください。

署名者
CN=Sunimori, OU=Tools, O=Sunimori, C=JP
SHA-256 指紋
34:20:B1:D6:73:C4:00:7B:E2:72:7F:D3:C8:3B:61:32 40:4A:69:A4:B3:EF:90:66:6A:0B:DE:0B:49:BB:23:32

信頼後に証明書を再度求められた場合は、更新を中止してください。

未署名を拒否

eclipse.ini に追加すると、未署名コンテンツを警告ではなく失敗にできます。

-Declipse.p2.unsignedPolicy=fail

オフライン導入
